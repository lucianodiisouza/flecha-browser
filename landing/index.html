Open-source browser for macOS · v0.1

The browser that knows you write code.

Flecha is a Chromium browser with a vertical sidebar, Spaces and a command bar that understands gh 482, JWTs and staging URLs. Built in the open, so it can't be switched off by a company changing its mind.

One key between local, staging and production

              
Press ⌥⌘E and the same page opens on the next environment, path and query intact. Flecha groups a project's origins and tells local from staging from production by their names.

Your dev servers, already in the sidebar

            
Flecha notices servers listening on localhost and lists them. A badge counts console errors, so you see a broken page before you switch to it.

Boosts in TypeScript, kept in git

              
Change any site with a script and some CSS. Boosts are plain .ts files in a folder you choose, so they get code review, history and your editor's autocomplete.

              
In progress

            

            
// boosts/github.com.ts · API sketch, may change
export default boost({
  match: 'github.com/*/pull/*',
  css: `.js-comment-hide-button { display: none }`,
  run() {
    // Collapse generated files in every PR
    for (const f of $$('[data-path$=".lock"]')) f.collapse()
  },
})

          


          

            

              
Let your coding agent see your tabs

              
Flecha runs an MCP server, so Claude Code, Cursor and other agents can read the page you're on, its console and network errors, and act on them. Reading is the default. Clicking and typing stay off until you turn on full access in Settings.

Leaving Arc

          
Bring your Spaces, pinned tabs and favorites.

          
Arc is winding down. Flecha keeps the ideas you liked, the sidebar, Spaces, Peek and split view, and imports your setup in one step. It's a rewrite from scratch with no Arc code.
