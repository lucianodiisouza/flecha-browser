In progress

              
Boosts in TypeScript, kept in git.

              
Change any site with a script and some CSS. Boosts are plain .ts files in a folder you choose, so they get code review, history and your editor's autocomplete.

            

            
// boosts/github.com.ts · API sketch
export default boost({
  match: 'github.com/*/pull/*',
  css: `.js-comment-hide-button { display: none }`,
  run() {
    // collapse lockfiles in every PR
    for (const f of $$('[data-path$=".lock"]')) f.collapse()
  },
})

          


          

            

              
In progressMCP

              
Let your coding agent see your tabs.

              
Flecha runs an MCP server on 127.0.0.1, so Claude Code, Cursor and other agents on your Mac can read the page you're on, its console and its network errors. Reading is the default. Clicking and typing stay off until you turn on full access in Settings.

            

            

              
~/acme/web

              
› why does checkout redirect twice?

              
● flecha · read console localhost:3000/checkout

              
● flecha · network 302 /login → 302 /checkout

              
The auth middleware runs before the session cookie is set, so the first request has no session. Moving setSession() above requireAuth() fixes it.

            

          

        

      

    


    
    

      

        

          

            
Privacy

            
Local by design. Flecha collects nothing.

          

          
There is no Flecha server to send your data to. Don't take our word for it: the code is public.

        

        
        

          

            
Sent to Flechabytes

            
    
              
  • Usage analytics0
    • 
              
  • Crash reports0
    • 
              
  • Browsing history0
    • 
              
  • Account or sign-innone
    • 
            

            
Network traffic is the sites you open, your search engine, and updates for extensions and blocker lists.

          

          
    
            
  • 
              
    Your data is files on your Mac
    
              
    Tabs, Spaces, history and settings live in your user folder. Back them up, delete them or inspect them with any editor.
    
            
    • 
            
  • 
              
    Trackers blocked out of the box
    
              
    Ad and tracker blocking is built in and on by default, with EasyList, EasyPrivacy and uBlock lists. No extension to trust.
    
            
    • 
            
  • 
              
    Agents stay on your machine
    
              
    The MCP bridge only listens on 127.0.0.1. Agents can read by default; full control is a switch you turn on yourself.
    
            
    • 
            
  • 
              
    Spaces don't share cookies
    
              
    Each Space has its own cookie jar, so work and personal browsing can't see each other's sessions.

Open source

          
A browser you can read, build and fork.

          
Browsers backed by a company can disappear when the company changes its plans. Flecha's code is public, so if the project ever stops, your browser keeps working and anyone can pick it up.
